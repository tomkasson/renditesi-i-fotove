# Renditësi i Fotove

Program për Windows që analizon fotot e tua, gjen personat (fytyrat), i rendit në dosje dhe ndërton
**pemën e familjes dhe të lidhjeve** (shoqëria, shkolla, puna). Gjithçka punon **në kompjuterin tënd**:
asnjë foto nuk dërgohet jashtë.

## Instalimi (Windows 10 / 11)
1. Shkarko këtë depo si ZIP (butoni **Code → Download ZIP**) dhe hape.
2. Kliko dy herë **`Instalo-Renditesin.bat`**. Kërkon internet dhe zgjat 5–20 minuta.
3. Hape nga ikona **Renditësi i Fotove** në Desktop.

Të dhënat e tua (emrat, pema, korrigjimet) ruhen te `%LOCALAPPDATA%\RenditesiFotove\data`
dhe nuk preken kurrë nga përditësimet.

## Përditësimi
Te faqja **Skano** del njoftimi *"Ka version të ri"* → **Përditëso**. Merret vetëm kodi i ri.

## PC e vjetër (Windows 7)
Dosja **`mbledhesi`**: kopjon fotot e një PC-je të vjetër në USB (një ose disa), që të skanohen këtu.
Shih `mbledhesi/LEXOME.txt`.
